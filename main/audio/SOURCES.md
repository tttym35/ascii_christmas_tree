# Audio sources

Background music: `snow_music_box.wav`, made for this project in a separate
session (24 kHz mono 16-bit WAV). Its melody distribution rights are tracked
outside this repository.

Interaction effects: `sfx_*.wav`, generated by `generate_sfx.py` in this
directory. Every effect is synthesized from oscillators and shaped noise by
that script, so the project owns the files outright under the repository
licence; no third-party samples, authors or download links are involved.
The plan's Freesound/Pixabay CC0 candidates were replaced by these generated
equivalents because Freesound downloads need an account; each generated
effect matches the planned character (wind chime, firework, fabric whoosh,
jingle bell, candy crunch, glass shatter, crystal twinkle, triple pop).
Two effects were added later in the same synthesized style: `sfx_star_ding.wav`
for tapping the treetop star and `sfx_snow_step.wav`, repeated crunchy snow
steps for a tapped snow-ground animal.
Regenerate with `python3 generate_sfx.py`. Total embedded size is about
437 KB at 24 kHz mono 16-bit.
